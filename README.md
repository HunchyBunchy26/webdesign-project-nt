# Natalija Tiron WebDesign Project 

## Description

I chose to build this specific website is not only because it is close to my heart but also because I would like to show how beautiful my hometown, Daugavpils, is.

My website is built to target the audience that are eager in exploring new locations, new cuisine or simply to fulfil the knowledge of the history.

The website gives you brief guidelines in what to explore together with externally accessible links to get more detailed information about your possible upcoming trip to Daugavpils, Latvia.

## Features
* Responsive
* Accessible

## Accessibility Notes

Using DevTools accessibility points were checked and fixed. Some images were missing an alternative.

## Tests

HTML Code checked with HTML Validator. CSS checked with CSS Validator.
